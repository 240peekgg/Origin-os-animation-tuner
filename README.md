# OriginOS Animation Tuner

Rootless Android app for testing Vivo launcher animation presets with Shizuku and WRITE_SETTINGS, animated previews, backup/restore and signed APK builds

A precise system-wide independent open/close animation duration is **not yet available** through verified non-root APIs, so sliders are labelled preview-only

CI builds and verifies APK signatures v1 + v2 + v3
